# Khair-e-Ummah Welfare Society (A Project of Darul Taqwa) Official Mobile App

موبائل ایپلیکیشن برائے **خیر اُمہ ویلفیئر سوسائٹی (دارالتقویٰ)** جسے فلٹر (Flutter) فریم ورک پر بنایا گیا ہے۔

## 📱 اہم فیچرز (Key Features)
1. **اردو اور RTL سپورٹ (Urdu & RTL Typography):** خوبصورت اسلامی گرین اور گولڈن تھیم، نفیس نستعلیق فونٹس اور مکمل دائیں سے بائیں (RTL) انٹرفیس۔
2. **5 مین اسکرینز (Bottom Navigation):**
   - **ہوم (Home):** بینرز سلائیڈر، اہم 9 شعبہ جات، اعداد و شمار کا ڈیش بورڈ، فوری عطیہ بینر، آفیشل رابطے اور سوشل لنکس۔
   - **پروجیکٹس (Projects):** تمام فلاحی منصوبوں کی تفصیلی لسٹ، اہداف، موجودہ پیشرفت بار اور ایک کلک پر عطیہ بٹن۔
   - **ریکارڈ بک (Annual Records):** سال 2024، 2025 اور 2026 کے فلاحی پروجیکٹس کا ریکارڈ، سرچ بار، کیٹیگری فلٹرز اور پی ڈی ایف/رپورٹ حاصل کرنے کی سہولت۔
   - **عطیات و امداد (Donation & Aid):**
     - آن لائن عطیہ فارم جو خودکار طریقے سے واٹس ایپ پر تصویری/متنی رسید تیار کرتا ہے۔
     - مستحقین کے لیے امداد کی درخواست کا فارم۔
     - آفیشل بینک اکاؤنٹس (Bank Alfalah, Meezan Bank, EasyPaisa, JazzCash) بمعہ ون کلک اکاؤنٹ و IBAN کاپی فیچر۔
   - **تصویری گیلری (Gallery):** تمام فیلڈ ورکس، راشن تقسیم اور فلاحی سرگرمیوں کی تصاویر بمعہ زوم و فل اسکرین ویور (InteractiveViewer)۔

## 🚀 چلانے کا طریقہ (How to Run)

اگر آپ کے کمپیوٹر پر فلٹر انسٹال ہے تو درج ذیل کمانڈز چلائیں:

```bash
# 1. ایپ کے فولڈر میں جائیں
cd khair_ummah_app

# 2. تمام پیکیجز ڈاؤنلوڈ کریں
flutter pub get

# 3. ایپ کو موبائل یا ایمولیٹر پر رن کریں
flutter run

# 4. اینڈرائیڈ APK تیار کرنے کے لیے
flutter build apk --release
```
